Data source

Connect the dashboard to your published Google Sheet

Paste the published CSV link from your Google Sheet (File → Share → Publish to web → CSV).

How to set up the sheet

Row 1 holds the headings: Group · House · Colour · Emoji · Week 1 · Week 2 · … (add as many week columns as you need).

One row per group. Leave House blank if you're not using houses. Colour and Emoji are optional. Type attendance percentages into the week columns as they happen.

Then: File → Share → Publish to web → choose the sheet → Comma-separated values (.csv) → Publish → copy the link.
